# Prueba del Sistema CI/CD

Este es un archivo de prueba para verificar que el sistema CI/CD funciona correctamente.

## ✅ Verificaciones Automáticas

Cuando se cree el Pull Request, el sistema debe:

1. ✓ Validar estructura de archivos
2. ✓ Verificar que no hay archivos de video
3. ✓ Verificar que no hay archivos de seguridad
4. ✓ Ejecutar linter de Markdown
5. ✓ Escanear credenciales
6. ✓ Notificar a los revisores

## 🔒 Protección de Rama

El merge debe:
- Requerir aprobación de @RivaldoTJ
- Requerir que todos los checks pasen
- Requerir conversaciones resueltas
